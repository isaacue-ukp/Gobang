# Gobang 五子棋

一个 C++ 写的命令行五子棋，15×15 棋盘，两个人轮流落子，无禁手规则。

```
   01 02 03 04 05 06 07 08 09 10 11 12 13 14 15
01
02
03
04
05
06
07                         ##
08                      ## ##
09                      [] []
10
11
12
13
14
15
```

`##` 是玩家 1，`[]` 是玩家 2。

## 编译运行

需要一个支持 C++11 的编译器（g++ / clang++ / MSVC 都行）。以 MinGW 的 g++ 为例：

```bash
g++ -Wall -o gobang.exe Board.cpp Game.cpp main.cpp
./gobang.exe
```

## 玩法

输入坐标时**先写行、再写列**，范围 1~15，中间用空格隔开，比如落在棋盘正中间的 `8 8`。

- 先连成五子的一方获胜，横、竖、两条斜线都算
- 棋盘下满还没人连成五子算平局
- 输入的不是数字，或者坐标超出 1~15，程序会提示重输，这一步不算
- 想中途退出，直接结束输入：Windows 按 `Ctrl+Z` 再回车，Linux / macOS 按 `Ctrl+D`

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `main.cpp` | 程序入口，构造 `Game` 然后跑起来 |
| `Board.h` / `Board.cpp` | 棋盘：落子、判空、判胜、判满、打印 |
| `Game.h` / `Game.cpp` | 对局流程：读输入、换手、判胜负 |

棋盘内部用 `cells[row][col]` 存，下标 0~14；显示和输入用 1~15，换算只在 `Game::getPosition` 里做一次。
